Catalogue

Sixteen abstractions with separate responsibilities

Software uses abstractions to span operating systems and libraries. OA carries the same idea into capabilities supplied by local programs, operating-system facilities, and remote services. Choose the smallest abstraction your application or provider needs. Open the technical detail for contracts, clients, source publication and recorded language results.

Repository presence and a source build are separate from installed readiness. Language support records which language clients are checked against the runtime.

facade

Resolve a capability through one local OA service while providers and service locations can change.

abstraction-facade · Public source

Durable jobs

Submit work once, save its identity and observe, cancel or recover the same accepted work.

abstraction-job · Public source

abstraction-download · Public source

Settings

abstraction-config · Public source

abstraction-credentials · Public source

Structured events

abstraction-logging · Public source

Shared content

Find bytes by content fingerprint, then read, write and watch them for changes within size limits.

abstraction-storage · Public source

Watch

Turn polled or pushed values into current snapshots, quiet notices, or one callback after a burst settles.

abstraction-watch · Public source

Permissions

Decide and administer which verified programs may use each capability or operator action.

abstraction-rights · Public source

Questions

abstraction-asks · Public source

Caller identity

Model inference

Contracts, clients and source routes

Measured on 2026-11-23. Each language row gives the module's state on Language support, linked to its entry there, then the client: the facade's resolve accessors, or for JavaScript the generated service clients a binding from Machine.resolveService wraps. Checked means that language's client or record types passed a recorded check against the running OA runtime; available means a client exists and no current check is recorded. Test connection marks a checked state whose check passed only over the Go IPC connection, the test-only pipe connector or a connection the check did not record. Ship on a checked state on your platform.
