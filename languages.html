What a badge means

badgemeans
Recordsgenerated record types and codec only; no generated service interface
Interfacea generated service interface is present
Clienthand-written public source beside the generated package
Facadeabstraction-facade carries a resolver accessor for this capability in this language
Packagethe language's package metadata file is committed beside the cell
Servicehand-written Go source implementing the capability's service side
Proven PASS / Proven FAILa recorded transcript reached that verdict for this cell; the badge links to it
—no implementation of this abstraction in this language

Nothing here carries an API stability promise. A missing badge means this walk of the tree and the evidence did not find that fact.
