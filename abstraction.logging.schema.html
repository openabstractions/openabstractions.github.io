Service result postcondition: usage is present exactly when outcome is available. Clients validate before return; dispatchers validate before reply. Standalone record codecs remain structural.

Read retained records through the service. Empty cursor starts at earliest retained history. Read one or all emitting programs' records from the runtime's memory rings (ruling A3, 2026-11-22), every level included. memory_only true returns only records the store kept in memory alone when it admitted them. Bounds are 1..256 returned records and 1..1048576 encoded Record bytes; a page also fits one default IPC frame and may stop before max_bytes. Empty cursor starts at the oldest record held; end fixes the current end. At an empty current end the call waits up to wait_ms (0..30000) for a new record, then reads once more. Admission is application-log@1 with its per-emitter blocks, as for Read. In addition, a proven program's one-app read of its own records needs no rule, except for a shared interpreter, and the person's own log viewer, which the runtime names and which holds the reader@1 whole-history permit, reads every application's records in memory. Out-of-range bounds return invalid with the cursor preserved. A provider without memory rings returns unsupported. An earlier reader@2 service answers unknown_method.

Sources

request-response SourceCatalog · readonly [DEF-S3]

Read one fixed source with bounds of 1..256 entries and 1..65536 encoded SourceRecord bytes. The service checks the exact source-specific right before native access. A provider without a source returns unsupported; OA policy denial returns not_permitted, known native access denial returns forbidden and uncertainty returns unavailable. Invalid semantic bounds return invalid. Refusals contain no records, preserve the supplied cursor and never announce end. Empty cursor starts at the earliest visible retained entry the native API exposes. Cursors bind source ID and reader instance; source mismatch, restart or retention loss returns gap and preserves the cursor. No cross-source ordering, complete-capture claim or observation guarantee is made.

  • Argument 3: i64 max_records (required, including zero/false/empty)

Return an opaque baseline cursor at the source's current end without returning records. The exact source-specific right is checked before native access and rechecked before the cursor is returned. A source without a safe current-position operation returns unsupported. Enumerations [DEF-T5]

Enum fields carry JSON strings containing exact member wire spellings, never numeric IDs. Unknown names are preserved with grant and refused as bad_enum with refuse on read and write. Optional absent fields preserve presence separately from an empty string.

An enumeration is a closed vocabulary of wire names, and each one says on its own what a reader does with a member it has never heard of [DEF-A5].
